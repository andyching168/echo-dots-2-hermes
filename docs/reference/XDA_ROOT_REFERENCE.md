# Echo Dot 2 unlock/root reference

The Hiyo deployment begins after the Echo Dot 2 has a working root shell. The
unlock / TWRP / recovery work is based on the XDA Developers thread by @R0rt1z2
and tooling credited there to @k4y0z:

<https://xdaforums.com/t/unlock-root-twrp-unbrick-amazon-echo-dot-2nd-gen-2016-biscuit.4761416/>

This repository intentionally does **not** reproduce the forum post verbatim.
Follow the upstream thread for its current instructions and downloads, then use
`../RECOVERY_GUIDE.md` for the Hiyo-specific installation steps.

The local research archive may contain an offline copy for personal provenance;
it is not part of the public distribution.
